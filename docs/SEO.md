# Compress100 SEO Specification

## URL Map

| URL | Primary query | Page intent |
| --- | --- | --- |
| `/` | compress image to 100kb | General target-size compressor |
| `/gif-compressor` | gif compressor | Animated GIF compression |
| `/compress-to-50kb` | compress image to 50kb | Strict upload limit |
| `/compress-to-200kb` | compress image to 200kb | Forms and profile images |

Each URL owns its keyword, title, description, H1, FAQ copy and canonical URL. The shared tool is implementation reuse, not duplicate page copy.

## Technical SEO

- Static route HTML must contain the H1, product explanation and FAQ before hydration.
- `WebApplication` describes the browser tool and links the upstream PicLite project through `isBasedOn`.
- `FAQPage` is included for semantic clarity; rich-result eligibility is not assumed.
- `sitemap.xml`, `robots.txt`, canonical URLs, Open Graph and a manifest are generated by the app.
- Submit all four URLs in Search Console after the production domain is verified.

## Measurement

Track page views, file-add starts, completed compressions, reached-target rate and downloads. Do not send filenames, image pixels or image hashes to analytics.
