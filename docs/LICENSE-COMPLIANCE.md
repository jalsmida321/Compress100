# GPL Compliance Notes

Compress100's web product reuses and derives browser code from [PicLite](https://github.com/amiaoapp/PicLite), which is distributed under `GPL-3.0-or-later` and includes adaptations from Clop.

This product keeps the upstream `LICENSE`, `THIRD_PARTY_NOTICES.md` and source attribution. The footer links to the upstream source and GPL text.

The browser receives JavaScript and therefore the product must not claim that modified GPL-derived client code is proprietary merely because the server does not process images. Keep corresponding source available under the applicable GPL terms when distributing the modified web application. Confirm the permitted use of the PicLite name, logo and other marks with the upstream maintainers before presenting Compress100 as an endorsed product.

This document is an engineering checklist, not legal advice. Have counsel review any paid distribution, trademark use or third-party asset changes.
