# Compress100 Design System

The interface follows the `Ui` style reference from Refero Styles: a clinical, monochromatic developer-tool surface with hairline borders and quiet elevation.

## Tokens

- Canvas: `#f5f5f5`
- Paper: `#ffffff`
- Alternate surface: `#fafafa`
- Ink: `#0a0a0a`
- Muted text: `#737373`
- Hairline: `#e5e5e5`
- Error only: `#e7000b`
- Interactive radius: `18px`
- Container radius: `24px`
- Base spacing: `4px`

## Rules

- The upload tool is the primary experience, not a promotional card.
- Use black for the main action and red only for destructive/error states.
- Keep body copy at 14px or larger and preserve visible keyboard focus.
- Use Lucide icons for interface controls and provide labels for unfamiliar actions.
- Do not introduce gradients, decorative blobs, colored shadows or emoji controls.
- Test at 320, 375, 414, 768, 1024 and 1440px widths.
